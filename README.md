## 📂 Estrutura do repositório

Todo o conteúdo fica dentro da pasta `CursoHtml/`, dividida em uma pasta por aula (`aulaHtml1` até `aulaHtml14`). Cada aula parte da anterior e vai incorporando novos conceitos de HTML, então dá pra acompanhar a evolução do aprendizado pasta por pasta:

| Pasta | Conteúdo abordado |
|---|---|
| `aulaHtml1` | Estrutura básica de um documento HTML (`<html>`, `<head>`, `<body>`, títulos e parágrafos) |
| `aulaHtml2` – `aulaHtml5` | Elementos de texto e estruturação da página |
| `aulaHtml6` | Páginas adicionais (`sobre.html`) e metatags (`description`, `keywords`, `author`) |
| `aulaHtml7` – `aulaHtml9` | Página de equipe (`equipe/pedro.html`) e trabalho com imagens (`img/`) |
| `aulaHtml10` | Organização de páginas (`index.html`, `sobre.html`) e imagens |
| `aulaHtml11` | Formulários HTML (`formulario.html`) |
| `aulaHtml12` | Inclusão de áudio (`audio.html`) |
| `aulaHtml13` | Inclusão de vídeo (`video.html`) além de áudio |
| `aulaHtml14` | HTML semântico (`semantico.html`) e estilização com CSS incorporado |

Além disso, o repositório conta com um arquivo `.hintrc`, usado para configurar o linter [webhint](https://webhint.io/) no VS Code.

## 🎯 Objetivo

Este repositório tem propósito **didático**: serve como registro pessoal do progresso em um curso introdutório de desenvolvimento web, cobrindo desde a estrutura básica de uma página HTML até tópicos mais avançados, como formulários, mídias (áudio e vídeo) e HTML semântico com estilização em CSS.

## 🚀 Como visualizar

Como são páginas HTML estáticas, basta:

1. Clonar o repositório:
   ```bash
   git clone https://github.com/PedroHsBz/SiteEmHtmlOrCss.git
   ```
2. Entrar na pasta da aula desejada (ex.: `CursoHtml/aulaHtml14`).
3. Abrir o arquivo `index.html` (ou outro arquivo `.html` da pasta) diretamente no navegador.
